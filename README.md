# SAREX Fitness Clinic

SAREX Fitness Clinic is a web application for managing a gym and its member services. The public site presents membership plans, facilities, services, events, and contact information. Members can manage their accounts and memberships, pay online, view workout plans and attendance, and register for events. Staff and administrators manage members, plans, payments, check-ins, services, events, contact messages, and clinic operations. Trainers manage assigned members and their workout plans. SAREX AI answers questions about the clinic, memberships, fitness, and training.

## Technologies

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Recharts, React Markdown
- **Backend:** Node.js, Express, PostgreSQL, `pg`, Zod
- **Payments:** Paystack
- **AI:** Groq AI
- **Media:** Cloudinary
- **Deployment:** Vercel for the frontend and Render for the API
